## Vercel handoff

Import the GitHub repository, choose Root Directory `Website`, Node.js 22.x, then deploy. Build: `npm run build`; output: `dist`; install: `npm ci` (already configured in Website/vercel.json). Downloads are served by GitHub Releases. No database, API token, Python or Electron is needed on Vercel. For a custom domain set SITE_URL to its actual HTTPS origin; otherwise the build uses Vercel's production-domain environment variable.
