Optional setup

Keyword discovery and virtual grouping work without neural models. Meaning retrieval and query interpretation require explicitly enabled local models. Scanned-page OCR uses a separate pack; visual descriptions need optional vision-model setup. Downloads require an internet connection and your explicit action. Routine processing and inference stay on the device.

Verification and limits

The 0.4.3 source passed 142 backend tests, 11 discovery browser flows, packaged application and frozen-service checks, and 22 updater tests. Frozen updater verification matched the current installer. These results describe tested integration behavior, not factual-answer accuracy.

Experimental explanations reproduced factual mistakes and need checking against course material. An actual installed upgrade and clean-machine acceptance have not been exercised. Both installers are unsigned. No automatic online update feed, macOS package or Linux package is configured.
