Current core library

  • Index PDF, DOCX, and TXT files from user-approved folders.
  • Search exact terms in filenames and extracted document text.
  • Monitor approved folders, rescan, pause, remove, and inspect scan notices.
  • Read document details and extracted text while preserving originals.
  • Store the index locally, without a cloud account.
  • Use the midnight study-room interface, local fonts, keyboard controls, and reduced motion.

SIFT V0 Beta · 0.3.3

The complete Windows x64 installer includes the desktop app and its local service. It runs without separately installing Python or Node.js. Public availability is shown above.

Installer details

Included in the beta

  • Conversational file discovery, editable virtual sections, syllabus collections and Windows shortcut exports.
  • Optional local models for meaning-based retrieval and query interpretation after explicit setup.
  • A separate optional OCR pack for scanned documents; no model or OCR downloads are bundled in the installer.
  • The 0.3.3 rename-continuity fix preserves document identity and citations when a source is renamed during a scan.

Installation and updates

Download one installer from GitHub Releases. The same installer can upgrade an existing installation using SIFT's original NSIS identity. Approved documents, local library data and model storage are preserved. The installer is unsigned. No automatic online update feed is configured.

Verification and beta limits

The local release passed frozen-service smoke and updater verification. A real installed upgrade and clean-machine installation have not been exercised. No new real neural-model inference or OCR quality benchmark is claimed. This is a beta release.
